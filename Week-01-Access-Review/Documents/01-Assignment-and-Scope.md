# Assignment & Scope

**Week 01 · User Access Review**  
**Scenario date: 5 October 2026**

## The Request

> “We've never properly reconciled the patient admin portal against HR. Here are both exports. Tell me what's wrong, what to fix first, and how we stop it happening again.”

## Assessment Objectives

- Identify inappropriate, excessive, or insufficiently justified access.
- Assess the risks and prioritise findings by severity and business impact.
- Recommend corrective actions and preventive controls.

## Scope

Review seven patient administration portal accounts against five supplied HR records, covering:

- Employment status, end dates, and login activity.
- Assigned roles and business justification.
- Account ownership, shared credentials, and credential storage.
- Access requirements during extended leave.

Implement selected access changes in Microsoft Entra ID using PowerShell, then test and document the results.

## Deliverables

| Deliverable | Contents |
|---|---|
| User Access Inventory | Portal accounts reconciled against HR records |
| Findings & Recommendations | Issues, supporting evidence, severity, recommended actions, and first priority |
| Access Risk Methodology | Criteria used to assess severity and prioritise findings |
| Executive Summary | Findings and priorities for the IT manager, within 100 words |
| Preventive Controls | Controls or process changes for each issue type |
| Lab & Testing | Implementation walkthrough, PowerShell scripts, and test evidence |
| Review | Outcomes, feedback, and outstanding actions |
