# The 90-Day IAM Analyst Project

**One IAM assignment a week for 90 days: investigate, recommend, implement, verify.**

I take on the work of an IAM analyst. Each assignment starts with a business request, and findings, recommendations, implementation, and test results are documented as the work progresses.

## The Setting

**Northwind Health** is a fictional, 120-person US healthcare SaaS company that stores electronic protected health information (ePHI) for approximately 400 clinics.

The same company context runs through the series. Each week introduces a different ticket with its own business requirements. Technical work takes place in my own test environment.

## Inside Each Week

- **README:** The ticket, my approach, and a summary of the results.
- **Documents:** Scope, findings, recommendations, supporting assessments, preventive controls, and review.
- **Lab & Testing:** Implementation, scripts, and test evidence.

Recommendations are labeled separately from changes I implemented and validated.

## Review

Selected assessments are reviewed by a practicing CISO. Each week’s review document records the feedback received, what I changed in response, and a link to the revised work.
