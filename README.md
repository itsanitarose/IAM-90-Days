# The 90-Day IAM Analyst Project

**One IAM assignment at a time: investigate, recommend, implement, verify.**

## The Setting

Northwind Health is a fictional, 120-person US healthcare SaaS company storing electronic protected health information (ePHI) for approximately 400 clinics. Each assignment addresses a different business request. Technical work takes place in my own test environment.
